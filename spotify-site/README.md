# Spotify 中文产品导览

PC 静态网站，1280—1920px 桌面窗口，无构建步骤、无第三方 JavaScript 依赖。

```sh
python3 -m http.server 8765 --directory dist
```

打开 http://localhost:8765 。官方素材和 Spotify Embed 需要网络。

- 22 张经过 Spotify 官方页面核验的专辑组成动态背景，各列使用独立序列，缓慢交错移动。
- 开场约 4.6 秒：暗场近景 → 镜头拉远、画面展开 → 标题 → 简短介绍与入口。
- 按最新设计要求移除所有展示动画开关和跳过按钮；滚动与键盘聚焦可直接结束开场，不劫持滚动。系统 prefers-reduced-motion 自动呈现静态画面。
- 精简首屏与第一章文字，专辑画廊统一对齐；搜索、发现标签、音乐库步骤和 Connect 使用讲解可操作。
- 音乐仅由用户点击 Spotify 官方 Embed 播放。播放器按需加载，关闭或切换后销毁旧 iframe。
- 官方桌面演示来自 Spotify Newsroom 2023 年报道，始终静音，并明确标注日期和演示性质。离屏、后台或系统减少动画时暂停。视频约 26.9 MiB，首屏不播放该视频。
- 没有连接账户、生成个性化推荐、收藏内容或连接真实设备。
- 封面使用官方 CDN，原始图片文件未修改。按本次明确的设计要求制作的动态封面背景偏离 Spotify 官方不对封面做动画的规范；不能视为完全符合官方素材规范。静态专辑与来源弹窗提供原始 Spotify 链接。
- 本站是独立产品导览，非 Spotify 官方网站；来源链接在页脚。

测试情况见 VALIDATION.md。
